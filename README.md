# SQL Project & Reference Guide


## Summary
This repository serves as a centralized SQL mastery guide and problem-solving repository tailored for Data Analysts, BI Engineers, and Analytics Engineers. It demonstrates query design across core relational concepts, window functions, complex joins, Common Table Expressions (CTEs), cumulative metrics, and business logic patterns across leading assessment platforms.

---

- **Total Solved Queries:** 133 production SQL scripts.
- **Platform Breakdown:**
  - **DataLemur:** 59 problems (advanced real-world analytics, retention, growth, rolling metrics).
  - **HackerRank:** 52 problems (fundamental filtering, grouping, string parsing, subqueries).
  - **LeetCode & SQLZoo:** 22 problems (classic ranking, self-joins, consecutive events, conditional aggregations).
- **Core SQL Patterns Covered:**
  - Window Functions (`DENSE_RANK()`, `ROW_NUMBER()`, `LAG()`, `LEAD()`, Rolling Averages).
  - Advanced Aggregations & Pivoting (`CASE WHEN`, `COALESCE()`, `GROUP BY`, `HAVING`).
  - Complex Joins & Set Operations (`LEFT`/`INNER`/`SELF JOIN`, Subqueries, CTEs).
  - Relational Schema Design (DDL constraints, indexing, transactions).
